# Code of Conduct

LLM Router uses a simple contribution standard: be direct, respectful, and focused on improving the project.

## Expected behavior

- Keep discussions technical and evidence-based.
- Assume good intent while still asking for clear reproduction steps and tradeoffs.
- Respect that routing, pricing, and provider compatibility can vary by upstream.
- Do not post API keys, private prompts, customer data, or credentials.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing someone else's secrets, logs, or private data.
- Spam, low-effort promotion, or unrelated arguments.
- Repeatedly ignoring maintainer decisions after a rationale has been provided.

## Enforcement

Maintainers may edit, hide, lock, or delete comments and issues that violate this code. Serious or repeated violations may lead to a block from the project.
