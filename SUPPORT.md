# Support

Use GitHub issues for reproducible bugs and feature requests:

https://github.com/study8677/llm-router/issues

Before opening an issue:

- check that your upstream `UPSTREAM_BASE_URL` supports `/v1/models`
- remove all API keys from logs
- include the virtual model used: `auto`, `auto-coding`, or `auto-longtext`
- include whether `stream: true` was enabled

For security issues, use the private reporting flow in `SECURITY.md`.
